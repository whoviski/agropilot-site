# Аудит сторонних компонентов

Дата проверки: 9 ноября 2026 г.  
Объект: статический сайт AgroPilot · YnDrone в этом репозитории (`index.html`, `privacy.html`, `terms.html`, `cookies.html`, `style.css`, `app.js`, `consent.js`, каталог `img/`).

Репозиторий не содержит `package.json`, `package-lock.json`, `requirements.txt`, `node_modules` и других манифестов зависимостей. Сборки и серверного кода нет. Проверка сделана по исходникам и по запросам локально отданных страниц.

## Что код реально делает с данными

- Форм, полей ввода, API и тел запросов нет. Удалять нечего: лишние поля не собираются.
- Пароли не вводятся и не пишутся в журналы. `console.log` / `console.*` в скриптах сайта нет.
- HTTP-cookie код не ставит (`document.cookie` не используется).
- `sessionStorage` не используется.
- `localStorage`: один ключ `agropilot-consent` после выбора в баннере. Значение не отправляется.
- Координаты мыши живут в памяти до перерисовки героя и не сохраняются.
- Необязательные скрипты перечислены в `OPTIONAL_SCRIPTS` в `consent.js`. Список пуст, поэтому согласие ничего стороннего не загружает.

## Что убрано

Сторонних трекеров, CDN и шрифтовых сетей в проекте не было, поэтому удалять было нечего. Новые внешние адреса не добавлялись.

## Хостинг

Код не копирует журналы GitHub Pages и не задаёт срок их хранения. Трансграничная передача, которую делает сам скрипт, отсутствует. Запрос статического файла при открытии сайта с GitHub Pages принимает инфраструктура за пределами Российской Федерации. Это свойство размещения, а не отдельный SDK.
